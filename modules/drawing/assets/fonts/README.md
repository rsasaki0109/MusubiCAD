DejaVuSans.ttf is an unmodified DejaVu Sans font from the installed trusted
fonts-dejavu-core system package. Its Bitstream Vera/DejaVu distribution license
is preserved in DejaVuSans.LICENSE. The Debian packaging license notices describe
packaging files; MusubiCAD redistributes only the unmodified font and its notices.

The font is bundled to make PDF shaping/embedding independent of system fonts.
Unsupported glyphs fail conversion; SVG consumers still choose their own fonts.
