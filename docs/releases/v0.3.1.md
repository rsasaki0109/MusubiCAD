# MusubiCAD CLI v0.3.1

Release preparation: these notes describe the source intended for v0.3.1.
Publication requires the annotated main tag, all four native release builds,
packaged tutorial gates and official asset verification. The previously published
v0.2.0 archives do not contain the flexible-assembly APIs below.

## Release recovery

The v0.3.0 tag failed because Windows checkout rewrote an immutable ASCII STL
attachment from LF to CRLF, changing its required SHA-256. v0.3.1 marks STL files
as Git binary assets and regression-tests real `core.autocrlf=true` checkout;
original asset bytes, hash guards and physical assertions remain unchanged.
It also exposes actual tutorial failures as check annotations and requires
Windows packaged tutorials on release-input PRs before artifact upload. The older tag remains unchanged.
No failed native gate may be skipped and no local binary is manually published.

## Flexible assemblies

- `set_instance_articulation` stores independent, parent-owned joint coordinates
  for copies of a child assembly without changing that child's document.
- `inspect_articulation_source` reports the exact child source/revision, admitted
  drivers and connector identities. MCP now exposes 36 tools.
- Parent-context signed distance and signed angle constraints solve bounded
  child coordinates analytically. Angle constraints carry an explicit branch;
  fully bound systems report `context_dof:0`.
- Regeneration uses scoped physical leaves for transformed geometry, BOM and
  native interference checks. Source snapshots, mandatory patch verification,
  refused edits and Agent Undo/Redo protect child files and parent history.

The supported system has fixed outer instances and immediate child mechanisms.
Free outer motion, nonlinear/deeper constraints, hierarchical motion/reach and
hierarchical URDF/HTML exports remain explicitly refused. Mock imported-mesh
mass/bounds/placement checks are supported; exact mesh intersection and inertia
are not claimed. See [ADR-059](../adr/ADR-059-scoped-flexible-subassemblies.md),
[ADR-060](../adr/ADR-060-bounded-mock-compound-members.md) and
[ADR-061](../adr/ADR-061-analytic-parent-context-constraints.md) for the
implementation boundaries.

## Reproducible distribution

Every intended native archive contains both the ellipse editing tutorial and
`ASSEMBLY-TUTORIAL.md`, runners, scenarios and complete slider/hinge mechanisms.
Release CI executes both tutorials with the extracted native executable before
upload. Python 3.10+ is required; these exercises require no model or GPU.
Independent dimensions, volume, centre, bounds, exported STL, source preservation,
refusals and Undo/Redo are checked through real MCP and Agent processes.

Windows native Tauri/WebView2 form editing is now exercised in CI. Desktop
artifacts remain separate from CLI releases and do not imply trusted signatures.
Actual Codex dispatch and Gemini extension startup are recorded, but Cursor and
authenticated Gemini editing remain unverified. Tutorial execution is not evidence
of those client sessions.

## Compatibility and upgrade

All workspace crates, desktop configuration and agent plugin manifests use the
same 0.3.1 version. Third-party dependency versions remain unchanged.
New `articulated_assembly` and `flexible_assembly` component-source guards make
older readers refuse documents whose physical semantics they cannot honor.
Do not remove those guards to open a new assembly with v0.2.0. Existing documents
without the new assembly data retain their existing format behavior.

For an official archive, verify its entry in `SHA256SUMS` before extraction and
execution, then follow `QUICKSTART.md` and both included tutorials. Checksums
provide artifact integrity, not a publisher signature. See the
[release contract](../developer-guide/releases.md) for publication and verification.

This release preparation does not change the fixed maturity rubric or award
additional points: general CAD remains approximately 50%, agent operation 90%.
